# E-Commerce Product Recommendation System

## Project Overview
This project recommends products to users based on their previous ratings using Machine Learning.

## Dataset
- Amazon Product Reviews Dataset

## Algorithm Used
- SVD (Singular Value Decomposition)

## Technologies
- Python
- Pandas
- NumPy
- Surprise Library
- Google Colab

## Results
- RMSE: 0.70
- MAE: 0.53
